Paralastro packages open-source components whose own licenses remain in force.

## FFmpeg and FFprobe

The desktop package stages the platform binaries supplied by the `ffmpeg-static` and `ffprobe-static` npm packages. Their license files are copied into `Contents/Resources/licenses` (macOS) or the equivalent resources directory on other platforms.

The selected FFmpeg build includes GPL components and is distributed under GPL-3.0-or-later terms. Before publishing a release, preserve its license, publish the exact corresponding source or a compliant written source offer, and record the package versions and checksums in the release manifest. See the upstream package and binary-provider notices for the exact build configuration.
